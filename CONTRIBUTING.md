# Colaborar con Cero

1. Instalá Node.js 22 o superior y ejecutá `npm ci`.
2. Ejecutá `npm test`. Las pruebas crean bases temporales separadas.
3. Para ver la interfaz con datos ficticios, ejecutá `node scripts/preview.js` y abrí la URL local que imprime.
4. Explicá el problema, el cambio propuesto y cómo lo verificaste al abrir una pull request.

Los importes son guaraníes enteros. Las transferencias no deben contarse como gastos o ingresos. Una vista o herramienta nueva debe usar las validaciones del motor común.

Usá una carpeta temporal con `BUDGET_DATA_DIR` para probar cambios manuales. No incluyas datos financieros reales, rutas personales, credenciales ni respaldos en commits, capturas o issues.

Para escritorio, consultá los requisitos y los comandos de compilación del README. Las contribuciones se distribuyen bajo la licencia MIT del proyecto.
