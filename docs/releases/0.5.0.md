# Nemein v0.5.0 — Conectores WASM, API local e importación de extractos

Versión experimental para Windows x64, de código abierto bajo licencia MIT. Incluye las mejoras posteriores a la release 0.4.0.

## Novedades

- Conectores WASM: un conector recibe el archivo que elegís y devuelve un lote de importación v1, que pasa por la misma previsualización, deduplicación y confirmación de siempre. Corre en un proceso aparte, `nemein-connector.exe`, encerrado en un AppContainer sin capacidades y en un Job con tope de memoria y de tiempo. Si no se puede encerrar, no corre. El propietario instala, habilita y revoca desde la pantalla nueva **Conectores**; la firma Ed25519 informa quién firmó un componente, sin bloquearlo. Incluye el contrato WIT `nemein:connector@1.0.0`, un SDK en Rust y un conector de ejemplo para un banco ficticio. [Conectores](https://github.com/Danor07/nemein/blob/v0.5.0/docs/conectores.md).
- Importación de extractos OFX 1.x, OFX 2.x y camt.053, sobre el contrato de importación v1. Nada se redondea, convierte ni adivina: una fracción, otra moneda o un asiento no contabilizado rechazan el archivo. [Importaciones](https://github.com/Danor07/nemein/blob/v0.5.0/docs/importaciones.md).
- API HTTP local v1.1.0, apagada por defecto: se activa con `BUDGET_LOCAL_API=1`, escucha sólo en `127.0.0.1` y usa los mismos permisos, propuestas y auditoría que la CLI y el MCP. OpenAPI 3.1 generado y un flujo de eventos SSE reanudable. [API local](https://github.com/Danor07/nemein/blob/v0.5.0/docs/api-local.md).
- Permisos agrupados: un solo formulario por conexión, grupos «Consultas y respaldos» y «Cambios en datos», un control para toda la conexión y guardado sin recargar.
- Migración SQL 7, transaccional, que agrega `connector_batches` para los lotes preparados.
- La puerta de permisos queda registrada como escenarios reproducibles, que la prueban paso a paso.

## Descargar e instalar

Descargá Nemein-0.5.0-windows-x64-selfsigned-setup.exe y verificá su hash con SHA256SUMS.txt. Requiere Windows x64 y WebView2; incluye Node.js y las dependencias.

El ejecutable de Nemein, el trabajador de conectores y el instalador están firmados con el certificado autofirmado de Innova-tech y sello de tiempo. No es una firma con confianza pública: SmartScreen puede mostrar una advertencia. El archivo .cer es sólo el certificado público; no se importa automáticamente como raíz de confianza.

Abrí el instalador con doble clic desde el Explorador. Evitá iniciarlo desde una terminal de una app MSIX, donde Windows puede redirigir la instalación a una carpeta privada.

## Actualizar

1. Cerrá Nemein y los clientes MCP/CLI y guardá una copia de la carpeta %LOCALAPPDATA%\PresupuestoCero completa. Es la única forma de volver a 0.4.0: no hay migración descendente.
2. Instalá 0.5.0 desde el Explorador. Se conservan la carpeta de datos y el identificador de instalación; la migración 7 se aplica al abrir.
3. Desde 0.4.0 las conexiones siguen siendo compatibles. Las acciones nuevas `connectors`, `connector-prepare` y `connector-import` comienzan negadas: concedelas expresamente si querés que un agente prepare o confirme importaciones con conectores.
4. Si venís de versiones anteriores a 0.4.0, seguí también los pasos de las [notas de 0.4.0](https://github.com/Danor07/nemein/releases/tag/v0.4.0).

Volvé a abrir el cliente MCP después de actualizar. El catálogo sigue teniendo 23 herramientas: las acciones de conectores se usan mediante `ejecutar_accion`. Esta publicación no instala ni renueva tus conexiones automáticamente.

## Contratos y límites

- Los conectores corren sólo en Windows. En Linux, que hoy sólo se compila en la CI, la pantalla dice que no corren; no hay un paquete Linux validado.
- Un conector no tiene imports: no ve la red, el disco ni el presupuesto, sólo el archivo elegido. HTTP con dominios listados queda para una entrega posterior.
- Los respaldos siguen siendo sólo el SQLite: no incluyen `connectors/`. La recuperación soportada se hace en una carpeta nueva, sin copiar `connectors/`, y después se reinstalan y habilitan los conectores. Para recuperar sobre una carpeta existente, revocá antes sus conectores o borrá `connectors/inventory.json`. Restaurar el SQLite también devuelve los permisos de agentes de ese momento: revisalos antes de volver a conectar clientes. [Respaldos](https://github.com/Danor07/nemein/blob/v0.5.0/docs/respaldos.md).
- La API local v1 sigue la política de deprecación de 90 días y dos versiones estables. Un lote de hasta 16 llamadas se ejecuta en orden, sin atomicidad conjunta.
- PYG sigue usando importes enteros y no hay motor cambiario: los extractos y conectores en otra moneda se rechazan.
