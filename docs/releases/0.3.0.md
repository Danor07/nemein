# Nemein v0.3.0 — Exportaciones y conexiones privadas

Versión experimental para Windows x64, de código abierto bajo licencia MIT. Incluye las mejoras posteriores a la release pública 0.2.0.

## Novedades

- Exportación financiera JSON de nueve conjuntos o CSV de movimientos mediante CLI y MCP. Incluye moneda PYG, unidad entera y cursor del mismo snapshot SQLite para continuar con eventos.
- Permiso export independiente, negado por defecto, con revisión y revocación. Las exportaciones excluyen credenciales, conexiones, permisos, auditoría y propuestas.
- Configuración MCP sin token visible: referencia un archivo de credencial privado, restringido al usuario y SYSTEM en Windows. Rutas verificadas hacia una instalación completa, con rechazo de carpetas de desarrollo y MSIX.
- Migraciones SQL numeradas 1–5, transaccionales y comprobadas con bases de versiones anteriores. Corrección de «Origen no permitido» al crear conexiones.
- Herramientas Windows resueltas por ruta del sistema; reglas inválidas se niegan. Descarga MCP con estado de preparación, errores persistentes y reintento.
- CI con análisis estático estricto, propiedades, fuzzing y dos gates independientes de mutación. Incluye instalación silenciosa en Windows limpio, acceso de Inicio, credenciales y MCP desde la instalación.

## Descargar e instalar

Descargá Nemein-0.3.0-windows-x64-selfsigned-setup.exe y verificá su hash con SHA256SUMS.txt. Requiere Windows x64 y WebView2; incluye Node.js y las dependencias.

El ejecutable y el instalador están firmados con el certificado autofirmado de Innova-tech y sello de tiempo. No es una firma con confianza pública: SmartScreen puede mostrar una advertencia. El archivo .cer es sólo el certificado público; no se importa automáticamente como raíz de confianza.

Abrí el instalador con doble clic desde el Explorador. Evitá iniciarlo desde una terminal de una app MSIX, donde Windows puede redirigir la instalación a una carpeta privada.

## Actualizar

1. Cerrá Nemein y los clientes MCP/CLI y guardá una copia de la carpeta %LOCALAPPDATA%\PresupuestoCero completa.
2. Instalá 0.3.0 desde el Explorador. Se conservan la carpeta de datos y el identificador de instalación.
3. Si venís de 0.2.1 o anterior, renová la conexión en Permisos y propuestas y descargá su configuración nueva. El token ya no va dentro del JSON.
4. Desde 0.2.2 las conexiones siguen siendo compatibles. Export comienza negado: concedelo expresamente si querés exportar.
5. Desde 0.1.0, creá una conexión y elegí sus acciones. Los interruptores BUDGET_MCP_WRITE y BUDGET_EVENTS_READ ya no conceden acceso.

La configuración MCP debe apuntar a Nemein instalado. Esta publicación no instala ni renueva tus conexiones automáticamente.

## Contratos y límites

Exportar devuelve metadatos y content; el cliente decide dónde guardar el archivo. Hasta 20.000 filas y 5.000.000 bytes UTF-8, sin salida parcial ni redondeos silenciosos. JSON financiero no sustituye el backup SQLite ni se restaura automáticamente. CSV conserva texto literal; en planillas, importá campos textuales como texto. No reimportes esta exportación como extracto bancario sobre el mismo presupuesto.

No se agregan HTTP/OpenAPI, sincronización entre dispositivos, monedas configurables ni un motor cambiario. PYG sigue usando importes enteros. El seguimiento de eventos conserva sus permisos y contratos existentes.

## Validación y recuperación

La evidencia de regresión, mutación e instalación se detalla en VALIDACION.md y en los checks de GitHub del commit publicado. Las pruebas usan datos ficticios y presupuestos temporales.

Si una actualización falla al migrar, su transacción se revierte. Antes de volver a una versión anterior, cerrá todos los procesos y restaurá la copia previa completa; no fuerces una versión antigua sobre un esquema futuro ni mezcles archivos WAL. Restaurar un backup también restaura los permisos de ese momento: revisalos antes de reconectar clientes.
